### 受け取った依頼（原文の要旨）

AIコーディングエージェント（Claude Code / Codex / Antigravity）の初心者・非エンジニアが、これを「入れる」と、そのエージェントがスムーズに欲しい開発をしてくれる。何度も再利用できる。
聞き返して確定した2点: **最初からお客さんにも配る** / **エージェント本体はすでに動かせている前提**。

### 配る形（利用者との対話で確定。Yes を受領済み）

**ブラウザの画面に数行書く → Markdownが1枚だけ自動でダウンロードされる → それをAIに渡す → AIが一式を取得して照合する。**
人の操作は「書く・コピーする・貼る」の3つだけ。コマンドを打つのはAI。顧客に git もアカウント登録もインストールも要求しない。
中身をAIに書かせない（生成させると劣化し、しかも成功して見える）。合否はハッシュの一致で決め、AIの判断に委ねない。
正解のハッシュは、利用者が自分で受け取った Markdown の中に置く（取得物と一緒に来た値で取得物を検証しても意味がない）。

### 旧・形態の決定（フォルダ書き出し案。破棄済み）

**相手のパソコンに何も入れさせずに使えるブラウザ上の画面**とし、そこから利用者が選んだフォルダへ一式を書き出す。
理由: 3つのエージェントはいずれもフォルダ内のファイルを読んで動くため、拡張機能やアプリ側からは行動を変えられない。変えられるのは**置かれるファイル**である。
副次的な理由: この形なら受入検査が `templates/e2e/` の Playwright 雛形にそのまま乗る。
